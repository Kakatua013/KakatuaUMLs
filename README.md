# KakatuaUMLs

Diagramas UML do sistema Kakatua Bikes, elaborados com **ModelIO**.

## Diagramas

- **Diagrama de Caso de Uso** — atores e funcionalidades do sistema
- **Diagrama de Componentes** — estrutura e relações entre os módulos
- **Diagrama de Implantação** — distribuição física e protocolos de comunicação
